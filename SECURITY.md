# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The NEUROSCAN team takes system integrity and medical data privacy seriously. If you discover a potential vulnerability in the inference server, web workstation, or data processing pipelines:

1. **Do NOT publicly disclose the vulnerability via GitHub Issues.**
2. Email the project leads directly at: `rehanrasool@iust.ac.in`.
3. Provide a detailed proof of concept (PoC) and instructions to reproduce.
4. We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
